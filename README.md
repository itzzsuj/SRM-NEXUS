# **SRM Nexus**

SRM Nexus is a **modern Alumni and Student Management System** for SRM University. It connects **students, alumni, and the university** to enable communication, collaboration, and career growth.

## **🚀 Features**
- 🌍 **Alumni & Student Networking**
- 📢 **Job & Internship Listings**
- 📅 **Event Management & Mentorship**
- 📊 **Admin Dashboard for Analytics**

## **🛠 Tech Stack**
- **Frontend:** React, Material UI
- **Backend:** Node.js, Express.js, MongoDB
- **Authentication:** JWT, MongoDBAtlas
- **Hosting:** AWS
